NewFriends

비공개 메시징을 통해 네트워크 간 친구를 사귀세요.

개요

NewFriends는 BungeeCord 및 Velocity 네트워크를 위한 모듈형 친구 시스템입니다. 플레이어는 클릭 가능한 버튼으로 요청을 보내고 수락하고, 각 친구의 현재 서버를 보여주는 친구 목록을 탐색하고, 친구를 제거하고 /f msg 및 /f r을 사용하여 비공개로 채팅할 수 있습니다. H2, MySQL, MongoDB 또는 JSON에 데이터를 저장하고 작업을 비동기식으로 실행합니다. 구성, 메시지 및 저장소는 런타임 시 다시 로드될 수 있습니다.

  • 클릭 가능한 버튼이 있는 친구 요청
  • 현재 서버와 MSG 바로가기가 포함된 친구 목록
  • 비공개 메시지 및 빠른 답장(/fr)
  • H2, MySQL, MongoDB 또는 JSON 스토리지
  • BungeeCord 및 Velocity에서 작동
  • 구성 가능한 비동기 작업
  • 프록시를 다시 시작하지 않고 핫 리로드
  • 선택적 RedisBunge 지원
메모: 별칭이 /f, /friend, /amigos 및 /amigo인 /friends 루트 명령.

단계별 설치

이 플러그인은 게임 서버가 아닌 프록시(BungeeCord 또는 Velocity)에 설치됩니다.
  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.

후크 및 통합

플러그인은 서버에 설치될 때 이러한 플러그인과 자동으로 연결됩니다.

RedisBungee선택 과목

다중 프록시: RedisBungee를 사용하여 프록시 간에 데이터를 동기화합니다.

구성 파일

모든 .yml 파일은 소스 코드에 있는 그대로 플러그인과 함께 제공됩니다. 하나를 클릭하면 보거나 복사하거나 다운로드할 수 있습니다.

파일은 기본값으로 표시됩니다. 파일을 복사하거나 다운로드하여 서버의 plugins/ 폴더에서 편집하세요.
