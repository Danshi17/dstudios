HubCore

The ultimate lobby core: menus, hotbar and more.

Overview

HubCore is a complete lobby core: /hub spawn, main world protection, configurable hotbar, menu system with actions and a BungeeCord server navigator. It adds scoreboard, tablist, tags and chat colors, cosmetics, launch plates, EnderButt, PvP mode and rank-based join/quit messages. Modules can be toggled in-game and from config.yml.

Features

  • Spawn via /hub and world protection
  • Configurable hotbar, menus and navigator
  • Scoreboard and tablist
  • Tags and chat colors
  • Launch plates and EnderButt
  • PvP mode and /mod moderation commands
  • Modules toggleable in-game
  • Rank-based join and quit messages

Installation

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.
