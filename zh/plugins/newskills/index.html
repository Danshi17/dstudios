NewSkills

mcMMO 风格的技能：升级并解锁能力。

概述

mcMMO 风格的技能套件，包含 20 多种技能（采矿、伐木、草药学、剑、射箭、钓鱼、驯服等）以及数百种主动和被动能力。它包括等级、XP、奖金、XP 率事件、XP/物品共享和聊天聚会、排行榜和可编辑的 GUI。支持 MySQL/H2/MongoDB 转换、PlaceholderAPI、WorldGuard、Vault、ViaVersion 和 Folia，具有多语言区域设置。

特征

  • 20 多种具有级别和经验的技能
  • 每个技能的主动/被动能力
  • XP 各方共享、物品共享和聊天
  • 通过 /mctop 和 /mcrank 的排行榜
  • 技能 GUI 和可配置指南
  • XP 速率事件和关卡广播
  • 具有转换功能的 SQL/NoSQL 数据库
  • Folia 兼容和 PlaceholderAPI
