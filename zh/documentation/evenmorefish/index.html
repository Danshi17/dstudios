EvenMoreFish

使用完全定制的鱼进行钓鱼比赛。

下载于:GitHub

概述

EvenMoreFish 是一款开源插件，可通过 60 多种自定义鱼、稀有度、长度和奖励来升级钓鱼。它可以让你通过老板栏和排行榜运行预定的或员工触发的比赛，还可以在 /emf 商店中出售渔获。它添加了定制鱼竿和鱼饵、鱼类日志、数据库支持的统计数据以及与流行插件的兼容性。

  • 超过 60 种开箱即用的定制鱼
  • 可配置的稀有度、长度和奖励
  • 与老板酒吧的预定比赛
  • /emf 商店并通过 /emf sellall 进行批量销售
  • 定制鱼竿和鱼饵
  • 鱼类杂志和 /emf 顶级排行榜
  • 具有捕获统计信息的 SQLite/MySQL 数据库
  • 插件、20 多个语言环境和 Folia 支持
笔记: Oheers、FireML 和 sarhatabaot 的第三方插件；版本 2.4.7-SNAPSHOT 的本地副本。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

命令

        
命令描述允许

  
    

      /emf shop
      
    

    
  		
  开店卖鱼
  emf.shop




  
    

      /emf sellall
      
    

    
  		
  卖掉库存中的所有鱼
  emf.sellall




  
    

      /emf top
      
    

    
  		
  显示玩家排行榜
  emf.top




  
    

      /emf journal
      
    

    
  		
  打开鱼日记
  emf.journal




  
    

      /emf toggle
      
    

    
  		
  切换钓鱼、bossbar 和捕获消息
  emf.toggle




  
    

      /emf next
      
    

    
  		
  显示下一场比赛的时间
  emf.next




  
    

      /emf applybaits
      
    

    
  		
  将诱饵涂在所持的鱼竿上
  emf.applybaits




  
    

      /emf admin competition start
      
    

    
  		
  手动开始比赛
  emf.admin
