nKoths

带有捕捉、全息图和奖励的定制 KOTH。

概述

完全可配置的 KOTH（山丘之王）插件：使用选择棒创建区域并设置捕获时间、所需玩家、竞争模式和预定激活。它包括全息图（DecentHolograms/FancyHolograms）、实时记分板、粒子以及进入、离开、捕捉或超时的效果。它添加了列表/编辑 GUI 菜单、命令奖励和部落、WorldGuard 和 PlaceholderAPI 支持。

  • 使用选择棒创建 KOTH
  • 捕获时间和所需的玩家
  • 竞争模式和预定激活
  • DecentHolograms 或 FancyHolograms 支持
  • 带有捕获进度的实时记分牌
  • 对进入、离开、捕获和超时的影响
  • GUI 菜单和带有聊天输入的 KOTH 编辑器
  • 奖励和部落支持 (UltimateClans)
  • WorldGuard 和 PlaceholderAPI
笔记: YAML 或 JSON 存储；示例 KOTH 包含在示例文件夹中。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

WorldGuard选修的

区域：将其区域与 WorldGuard 保护区整合。

DecentHolograms选修的

全息图：使用 DecentHolograms 显示全息图。

FancyHolograms选修的

全息图：用 FancyHolograms 显示全息图。

HeadDatabase选修的

Heads：允许您在菜单和项目中使用自定义 HeadDatabase 头。

UltimateClans选修的

部落：与 UltimateClans 部落集成功能。

TAB选修的

Tablist：通过TAB自定义选项卡列表。

nPrisonutils选修的

监狱实用程序：与 nPrisonutils 集成。

PinnaPrison选修的

监狱：将奖励和进步与 PinnaPrison 相结合。

nStaffMode选修的

Optional integration: enabled automatically when this plugin is installed.
