BlockRewards

Break blocks, level up and claim epic rewards.

Overview

BlockRewards turns mining into progression: every broken block advances the reward tiers defined in rewards.yml. Players open a menu with ready/locked/claimed states, claim configurable command rewards and toggle auto-claim with a cooldown. It also includes a prestige system that spends Vault money, plus placeholders, titles, sounds and particles.

Features

  • Progression by mined blocks
  • Menu with ready/locked/claimed states
  • Weighted command rewards
  • Prestige system with Vault cost
  • Auto-claim with cooldown
  • Placeholders and customizable menu
  • Virtual or physical block mode

Installation

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.
