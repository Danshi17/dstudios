NewStreams

안전한 링크 검증을 통해 스트림을 발표하세요.

개요

NewStreams를 사용하면 플레이어는 네트워크의 모든 서버에서 /directo <link>를 사용하여 라이브 스트림을 발표할 수 있습니다. 플러그인은 링크의 유효성을 검사합니다. HTTPS가 필요하고 알려진 스트리밍 플랫폼(Twitch, YouTube, Kick, TikTok 등)만 허용하고 악성 도메인이나 URL 단축기를 차단합니다. 공지사항은 완전히 구성 가능하며 마우스오버 텍스트가 포함된 클릭 가능한 링크가 포함되어 있습니다.

  • 네트워크 전체 스트림 공지
  • HTTPS 링크를 적용합니다.
  • 스트리밍 플랫폼 화이트리스트
  • 위험한 도메인 및 단축기를 차단합니다.
  • 마우스오버 텍스트가 있는 클릭 가능한 링크
  • 완전히 구성 가능한 공지 라인
  • /directo에 대한 전용 권한
  • 다시 로드 명령(/nsr)
메모: 스페인어로 된 메타데이터 및 메시지.

단계별 설치

이 플러그인은 게임 서버가 아닌 프록시(BungeeCord 또는 Velocity)에 설치됩니다.
  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.

후크 및 통합

플러그인은 서버에 설치될 때 이러한 플러그인과 자동으로 연결됩니다.

후크 없음: 외부 종속성 없이 독립형으로 작동합니다.

구성 파일

모든 .yml 파일은 소스 코드에 있는 그대로 플러그인과 함께 제공됩니다. 하나를 클릭하면 보거나 복사하거나 다운로드할 수 있습니다.

파일은 기본값으로 표시됩니다. 파일을 복사하거나 다운로드하여 서버의 plugins/ 폴더에서 편집하세요.
