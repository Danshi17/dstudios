ItemsRPG

레시피, 효과, 애드온이 포함된 맞춤형 RPG 아이템.

개요

ItemsRPG는 소모품, 무한 소모품, 무기, 도구, 방어구, 보조 아이템, 바닐라 쿨다운 아이템 등 맞춤형 RPG 아이템을 추가합니다. 아이템은 사용자 정의 레시피, 물약 효과, 사운드, 입자 및 폭발성 채굴과 같은 마법부여를 포함하는 게임 내 GUI를 통해 생성되고 편집됩니다. 또한 수동 작업(도구 가속, 갑옷 및 보조 작업), 외부 애드온 API 및 HeadDatabase 지원 기능도 제공합니다.

  • 맞춤 아이템: 소모품, 무기, 방어구, 보조무기
  • 게임 내 아이템 편집기 및 목록
  • 맞춤형 레시피
  • 바닐라 및 사용자 지정 재사용 대기시간
  • 폭발성 채굴 마법부여
  • 패시브 신속, 방어구 및 임시 작업
  • 외부 애드온 API
  • HeadDatabase 및 자리 표시자 지원
메모: ItemsRPG는 재생 영역이 있는 버전(여기에 설명된 버전: 선택 막대, 게임 내 편집기 및 zones.yml을 사용하여 채굴 영역 재생성, PacketEvents 필요)과 재생 영역이 없는 버전(영역 시스템이 없는 동일한 베이스)의 두 가지 버전으로 배송됩니다.

단계별 설치

  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.

후크 및 통합

플러그인은 서버에 설치될 때 이러한 플러그인과 자동으로 연결됩니다.

packetevents필수의

패킷: 고급 효과 및 시각 효과를 위해 클라이언트 패킷을 보냅니다.

HeadDatabase선택 과목

헤드: 메뉴와 항목에서 사용자 정의 HeadDatabase 헤드를 사용할 수 있습니다.

PlaceholderAPI선택 과목

자리 표시자: 메뉴, 점수판, 메시지에 자리 표시자를 노출하고 사용합니다.

WorldGuard선택 과목

지역: 해당 영역을 WorldGuard 보호 지역과 통합합니다.

WorldEdit선택 과목

선택: WorldEdit 선택을 사용하여 영역을 정의합니다.

ShopGUIPlus선택 과목

Optional integration: enabled automatically when this plugin is installed.

구성 파일

모든 .yml 파일은 소스 코드에 있는 그대로 플러그인과 함께 제공됩니다. 하나를 클릭하면 보거나 복사하거나 다운로드할 수 있습니다.

파일은 기본값으로 표시됩니다. 파일을 복사하거나 다운로드하여 서버의 plugins/ 폴더에서 편집하세요.
