nKoths

KOTHs personalizables con captura, hologramas y premios.

Resumen

Plugin de KOTH (King of the Hill) totalmente personalizable: crea zonas con la varita de selección y configura tiempo de captura, jugadores requeridos, modo disputado y activación programada. Incluye hologramas (DecentHolograms/FancyHolograms), scoreboard en vivo, partículas y efectos al entrar, salir, capturar o expirar. Suma menús GUI de lista y edición, recompensas por comandos y soporte de clanes, WorldGuard y PlaceholderAPI.

  • Creación de KOTHs con varita de selección
  • Tiempo de captura y jugadores requeridos
  • Modo disputado y activación programada
  • Hologramas DecentHolograms o FancyHolograms
  • Scoreboard en vivo con progreso de captura
  • Efectos al entrar, salir, capturar y expirar
  • Menú GUI y editor de KOTHs con chat input
  • Recompensas y soporte de clanes (UltimateClans)
  • WorldGuard y PlaceholderAPI
Notas: Almacenamiento YAML o JSON; ejemplos de KOTH incluidos en la carpeta examples.

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

WorldGuardOpcional

Regiones: integra sus zonas con las regiones protegidas de WorldGuard.

DecentHologramsOpcional

Hologramas: muestra hologramas con DecentHolograms.

FancyHologramsOpcional

Hologramas: muestra hologramas con FancyHolograms.

HeadDatabaseOpcional

Cabezas: permite usar cabezas personalizadas de HeadDatabase en menús e ítems.

UltimateClansOpcional

Clanes: integra funciones con los clanes de UltimateClans.

TABOpcional

Tablist: personaliza la tablist mediante TAB.

nPrisonutilsOpcional

Utilidades de prisión: integración con nPrisonutils.

PinnaPrisonOpcional

Prisión: integra recompensas y progresión con PinnaPrison.

nStaffModeOpcional

Integración opcional: se activa automáticamente si este plugin está instalado.
