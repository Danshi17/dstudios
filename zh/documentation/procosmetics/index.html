ProCosmetics

超过 15 种化妆品类别，让您的服务器熠熠生辉。

概述

ProCosmetics 带来了完整的化妆品系统，包含超过 15 个类别：小工具、宠物、坐骑、变形、气球、横幅、箭头和死亡效果、表情、微缩模型、音乐、粒子、状态和宝箱。玩家使用内置经济、Vault 或 PlayerPoints 以及完全可配置的菜单和预览来解锁和装备化妆品。它支持多个世界、WorldGuard 区域、PlaceholderAPI 和跨多种数据库类型的多服务器数据同步。

  • 超过15个化妆品类别
  • 小玩意、宠物、坐骑和变形
  • 内置经济、Vault 或 PlayerPoints
  • 带有结构和平台的宝箱
  • 可配置的预览菜单
  • 连接时自动恢复外观
  • 多世界和 WorldGuard 支持
  • 通过权限和占位符解锁奖励
笔记: ProCosmetics v2.0.8 (FilleDev)。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

NoteBlockAPI必需的

音乐：使用 NoteBlockAPI 播放音符块音乐。

Vault选修的

经济：使用 Vault API 向玩家收费和付款（与您的经济插件配合使用）。

PlayerPoints选修的

积分：使用 PlayerPoints 作为奖励和购买的货币。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

WorldGuard选修的

区域：将其区域与 WorldGuard 保护区整合。

WorldEdit选修的

选择：使用 WorldEdit 选择来定义区域。

EssentialsX选修的

基本命令：与 Essentials(X) 命令和实用程序兼容。

CMI选修的

与 CMI 命令和实用程序兼容。

Essentials选修的

基本命令：与 Essentials(X) 命令和实用程序兼容。

MVdWPlaceholderAPI选修的

占位符：通过 MVdWPlaceholderAPI 提供额外的占位符支持。

Multiverse-Core选修的

世界：与 Multiverse-Core 管理的世界兼容。

PremiumVanish选修的

Vanish：尊重处于消失模式的玩家（SuperVanish、PremiumVanish 等）。

PlotSquared选修的

绘图：将其功能与 PlotSquared 绘图集成。

SuperVanish选修的

Vanish：尊重处于消失模式的玩家（SuperVanish、PremiumVanish 等）。
