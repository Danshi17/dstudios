NewCosmetics

适合您服务器的终极化妆品套件。

概述

ProCosmetics 的一个分支，添加了完整的化妆品系统：小工具、坐骑、宠物、变形、箭头效果、微缩模型、横幅、表情、音乐等等。它包括可配置的 GUI 菜单、动画宝箱、稀有物品、硬币和小工具弹药。经济可以使用 Vault、PlayerPoints 或内置系统。支持 SQLite、MySQL、MariaDB、PostgreSQL 和 MongoDB，可选配 Redis 进行网络同步。

特征

  • 13 个类别：小工具、坐骑、宠物、变形、表情...
  • 动画宝箱
  • 可配置的硬币、弹药和稀有物品
  • 可定制的 GUI 和菜单项
  • Vault、PlayerPoints 或内置经济
  • SQLite、MySQL、MariaDB、PostgreSQL 和 MongoDB
  • 可选的 Redis 和占位符
  • WorldGuard 支持和外观恢复

命令

命令描述允许
/newcosmetics
别名: /nc · /newc
 新化妆品司令部 newcosmetics.command
/cosmetics
打开化妆品菜单。 newcosmetics.command.cosmetics
/equip
装备化妆品。 newcosmetics.command.equip
/unequip
取消装备化妆品。 newcosmetics.command.unequip
/unequipall
卸下你的化妆品。 newcosmetics.command.unequipall
/toggleselfview
切换自我视图 newcosmetics.command.toggleselfview
/nc add coins
为玩家添加金币 newcosmetics.command.add.coins
/nc add cosmetic
给玩家一件化妆品 newcosmetics.command.add.cosmetic
/nc addall cosmetic
给大家送化妆品 newcosmetics.command.addall.cosmetic
/nc platform create
创建宝箱平台 newcosmetics.command.platform.create
/nc item
获取菜单项 newcosmetics.command.item

安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。
