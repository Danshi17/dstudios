NewKB

将击退和攻击速度调整至完美。

概述

完整的服务器击退控制：调整水平和垂直击退、垂直限制、空气/地面摩擦力、冲刺乘数以及可配置窗口和减少的组合。它还允许您通过攻击速度配置攻击冷却时间。无需重新启动服务器即可实时更改值。

  • 水平和垂直击退可调
  • 可配置的空气和地面摩擦力
  • 带窗口和盖子的组合系统
  • 攻击冷却时间取决于攻击速度
  • 使用 /newkb 设置进行实时更改
  • 重新加载配置而不重新启动

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

无钩子：它独立工作，没有外部依赖。
