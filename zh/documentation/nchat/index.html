nChat

终极聊天：颜色、标签、私信和审核。

概述

Paper 的完整聊天套件。它提供了 Vault 前缀格式、冷却时间、单词过滤器、阻止的命令和 TAB、带有 /msg、/r、msgspy 和忽略列表的私人消息、用于聊天和昵称颜色（十六进制和渐变）的 GUI 菜单、自定义标签、基于排名的加入/退出消息和聊天小游戏。它还包括一个 Discord 桥、一个管理功能面板以及与 [item]、[inv] 和 [enderchest] 共享的物品/库存。

  • 带有 Vault 前缀和悬停/单击的聊天格式
  • 带有十六进制和渐变的聊天和昵称颜色
  • 具有每个排名限制的自定义标签
  • 私人消息、回复、msgspy 和忽略
  • 单词过滤器、冷却时间和阻止命令
  • 聊天游戏和 Discord 桥
  • 管理功能面板
  • 在聊天中分享物品、库存和末影箱
笔记: /tags 不在plugin.yml 中：它是动态注册的。根据 Paper 1.21.4 构建。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

HeadDatabase选修的

Heads：允许您在菜单和项目中使用自定义 HeadDatabase 头。
