newResources

通过资源包定制物品、方块和家具。

概述

Paper 1.18.2+ 的资源包管理器和自定义资产框架。它自动构建并提供包（包合并和内置 HTTP 服务器），并允许您使用自动模型数据创建物品、武器、工具、盔甲、方块、家具、模型实体和文本效果。包括提供项目、打开菜单、列出资源和预览效果的命令。

特征

  • 自动资源包生成
  • 包合并和内置HTTP服务器
  • 定制物品、武器、工具和盔甲
  • 可旋转的可放置方块和家具
  • 带锚点的模型实体
  • 使用着色器的文本效果
  • 带有 PlaceholderAPI 的菜单
  • 给出、列出、调试和文本效果命令

命令

命令描述允许
/newresources
别名: /nr · /nresources
 newResources 的主要命令。 —
/nreditor
别名: /nrmenu · /menueditor
 游戏内可视菜单编辑器。 —
/newresources reload
重新加载资产并重建 newresources.admin
/newresources build
构建资源包 newresources.admin
/newresources give <jugador> <id>
向玩家提供资产 newresources.give
/newresources menu <id>
打开资产菜单 newresources.menu
/newresources list [tipo]
按类型列出资产 newresources.admin
/newresources pack send <jugador|all>
发送包 newresources.pack
/newresources texteffect <list|code|preview|create>
管理文本效果 newresources.admin

权限

newresources.admin仅OP
newresources.give仅OP
newresources.menu每个人
newresources.place每个人
newresources.break每个人
newresources.pack仅OP
newresources.editor仅OP

要求

PlaceholderAPIExcellentCratesResourcePackManager
笔记: 需要 Java 21。

安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。
