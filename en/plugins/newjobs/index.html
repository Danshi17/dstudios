NewJobs

13 professions with XP, quests and contracts.

Overview

Jobs system with 13 default professions (miner, woodcutter, farmer, fisherman, hunter, builder, digger, crafter, enchanter, brewer, weaponsmith, rancher and explorer). Actions grant money, XP and points, with multiple simultaneous jobs, daily quests, temporary contracts, level rewards and prestige. Includes fully configurable GUI menus and a progress BossBar. Economy is delivered via Vault or commands.

Features

  • 13 default jobs, expandable via YAML
  • Money, XP and points per action
  • Daily quests and temporary contracts
  • Level rewards and prestige
  • Configurable menus with actions and sounds
  • Per-job XP BossBar
  • Vault or command-based economy
  • Anti-farming block protection

Installation

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.
