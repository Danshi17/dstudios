newNPCS

3D 모델을 지원하는 맞춤형 NPC.

개요

newResources 3D 모델을 지원하는 Paper용 NPC 시스템입니다. 게임 내 NPC 생성 및 편집: 엔터티 유형, 이름, 이동, 회전, 플레이어 보기, 장비, 권한 기반 또는 수동 가시성 및 클릭 동작. 여기에는 이벤트, 자리 표시자 및 모든 NPC의 부활이 포함된 공개 API가 포함되어 있습니다.

특징

  • 게임 내 NPC 생성 및 편집
  • newResources를 통한 3D 모델
  • 오른쪽/왼쪽 클릭 동작
  • 권한 기반 또는 수동 가시성
  • 장비, 모양 및 모델 규모
  • 이벤트가 포함된 개발자 API
  • PlaceholderAPI 및 YAML 저장

명령

명령설명허가
/npc
별칭: /newnpcs · /npcs
 newNPCS의 주요 명령입니다. —
/npc create
NPC 만들기 newnpcs.command.create
/npc displayname
NPC 이름을 설정하세요 newnpcs.command.displayname
/npc model
새로운Resources 3D 모델 할당 newnpcs.command.model
/npc action
클릭 동작 newnpcs.command.action
/npc visibility
볼 수 있는 사람을 통제하세요 newnpcs.command.visibility

설치

  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.
