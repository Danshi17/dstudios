nChat

Le chat ultime : couleurs, tags, DM et modération.

Aperçu

Une suite de chat complète pour Paper. Il fournit le formatage du préfixe Vault, les temps de recharge, le filtre de mots, les commandes et TAB bloqués, les messages privés avec /msg, /r, msgspy et les listes d'ignorer, les menus GUI pour les couleurs de chat et de pseudo (hexadécimal et dégradés), les balises personnalisées, les messages de connexion/sortie basés sur le classement et les mini-jeux de chat. Il comprend également un pont Discord, un panneau de fonctionnalités d'administration et le partage d'objets/inventaire avec [item], [inv] et [enderchest].

  • Format de discussion avec préfixe Vault et survol/clic
  • Couleurs de chat et de pseudo avec hexadécimal et dégradés
  • Balises personnalisées avec limites par classement
  • Messages privés, réponse, msgspy et ignorer
  • Filtre de mots, temps de recharge et commandes bloquées
  • Jeux de chat et pont Discord
  • Panneau de fonctionnalités d'administration
  • Partagez l'objet, l'inventaire et l'Enderchest dans le chat
Remarques: /tags n'est pas dans plugin.yml : il est enregistré dynamiquement. Construit contre Paper 1.21.4.

Installation étape par étape

  1. Téléchargez le plugin .jar et déposez-le dans le dossier plugins/ de votre serveur ou proxy.
  2. Installez l'une des dépendances dont vous avez besoin à partir de la liste des exigences.
  3. Redémarrez le serveur (ou exécutez /reload confirm) pour que le plugin démarre.
  4. Configurez le plugin via son config.yml et ses fichiers de données.
  5. Utilisez la commande reload du plugin pour appliquer les modifications sans redémarrer.

Crochets et intégrations

Le plugin se connecte automatiquement à ces plugins lorsqu'ils sont installés sur votre serveur.

PlaceholderAPIFacultatif

Espaces réservés : expose et consomme des espaces réservés dans les menus, les tableaux de bord et les messages.

HeadDatabaseFacultatif

Têtes : vous permet d'utiliser des têtes HeadDatabase personnalisées dans les menus et les éléments.

Chaque fichier .yml livré avec le plugin, exactement tel qu'il apparaît dans le code source. Cliquez sur l'un pour l'afficher, le copier ou le télécharger.

Les fichiers sont affichés avec leurs valeurs par défaut : copiez-les ou téléchargez-les et éditez-les dans le dossier plugins/ de votre serveur.
