nChat

El chat definitivo: colores, tags, mensajes y moderación.

Resumen

Suite completa de chat para Paper. Ofrece formato con prefijos de Vault, cooldown, filtro de palabras, bloqueo de comandos y TAB, mensajes privados con /msg, /r, msgspy e ignorados, menús GUI de colores de chat y de nick (hex y gradientes), tags personalizadas, mensajes de join/quit por rango y mini juegos de chat. También incluye puente con Discord, panel de features para admins y compartición de items e inventarios con [item], [inv] y [enderchest].

  • Formato de chat con prefijo Vault y hover/click
  • Colores de chat y nick con hex y gradientes
  • Tags personalizadas con límites por rango
  • Mensajes privados, reply, msgspy e ignore
  • Filtro de palabras, cooldown y comandos bloqueados
  • Juegos de chat y puente con Discord
  • Panel de features para administradores
  • Compartir item, inventario y enderchest en el chat
Notas: /tags no aparece en plugin.yml: se registra dinámicamente. Compilado sobre Paper 1.21.4.

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

HeadDatabaseOpcional

Cabezas: permite usar cabezas personalizadas de HeadDatabase en menús e ítems.
