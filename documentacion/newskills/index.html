NewSkills

Habilidades estilo mcMMO: sube de nivel y desbloquea poderes.

Resumen

Suite de habilidades tipo mcMMO con más de 20 skills (minería, tala, herboristería, espadas, arquería, pesca, doma y más) y cientos de habilidades activas y pasivas. Incluye niveles, experiencia, bonus, eventos de XP rate, fiestas con xp/item share y chat propio, leaderboards y GUI editables. Soporta bases de datos MySQL/H2/MongoDB con conversión, PlaceholderAPI, WorldGuard, Vault, ViaVersion y Folia, con locale multi-idioma.

  • Más de 20 skills con niveles y experiencia
  • Habilidades activas/pasivas por skill
  • Fiestas con XP share, item share y chat
  • Leaderboards con /mctop y /mcrank
  • GUI de skills y guía configurable
  • Eventos de XP rate y broadcasts de nivel
  • Bases de datos SQL/NoSQL con conversión
  • Compatible con Folia y PlaceholderAPI
Notas: Fork tipo mcMMO con locale multi-idioma; dependencias opcionales.

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

WorldGuardOpcional

Regiones: integra sus zonas con las regiones protegidas de WorldGuard.

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

VaultOpcional

Economía: usa la API de Vault para cobrar y pagar (funciona con el plugin de economía que tengas).

ViaVersionOpcional

Versiones: soporte para clientes de varias versiones mediante ViaVersion.

CombatTagOpcional

Combate: respeta el estado de combate de los jugadores.

HealthBarOpcional

Vida: muestra barras de vida personalizadas.

Archivos de configuración

Los archivos se muestran con sus valores por defecto: cópialos o descárgalos y edítalos en la carpeta plugins/ de tu servidor.
