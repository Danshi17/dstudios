nStaffMode

Mode personnel complet avec outils de modération.

Aperçu

nStaffMode offre à votre équipe un mode de travail complet avec une barre d'outils rapide : téléporteur, inspecteur de joueur, invsee, congélateur, disparition, téléportation aléatoire, détecteur de mines, test CPS, hache d'interdiction et vue du conteneur. Il comprend le chat du personnel et le chat du propriétaire sur les canaux BungeeCord, un menu du personnel en ligne à l'échelle du réseau, des alertes de minerai et des webhooks Discord. Il protège également les inventaires du personnel et recharge toute la configuration sans redémarrage.

  • Barre de raccourcis de l'outil Personnel configurable
  • Disparaître, geler, invsee et vue conteneur
  • Test CPS silencieux de 15 secondes
  • Discussion entre le personnel et le propriétaire entre les serveurs
  • Menu du personnel en ligne avec téléportation
  • Menu d'interdiction avec des raisons configurables
  • Alertes diamant, netherite et géniteurs
  • Webhooks Discord pour les jointures et les punitions
Remarques: Configuration et messages en espagnol ; version 0.1-RC.

Installation étape par étape

  1. Téléchargez le plugin .jar et déposez-le dans le dossier plugins/ de votre serveur ou proxy.
  2. Installez l'une des dépendances dont vous avez besoin à partir de la liste des exigences.
  3. Redémarrez le serveur (ou exécutez /reload confirm) pour que le plugin démarre.
  4. Configurez le plugin via son config.yml et ses fichiers de données.
  5. Utilisez la commande reload du plugin pour appliquer les modifications sans redémarrer.

Crochets et intégrations

Le plugin se connecte automatiquement à ces plugins lorsqu'ils sont installés sur votre serveur.

PlaceholderAPIFacultatif

BungeeCordFacultatif

Réseau : messagerie et fonctionnalités réseau via BungeeCord.
