NewReports

Rapports du joueur avec des alertes de webhook Discord.

Aperçu

NewReports ajoute un système de reporting à l'échelle du réseau pour BungeeCord : /report <player> <reason> alerte le personnel avec un message qui comprend un bouton cliquable pour se connecter au serveur du joueur signalé. Il peut également envoyer le rapport sous forme de webhook Discord intégré. Il comprend un temps de recharge configurable, un blocage d'auto-rapport, des vérifications d'autorisation et un rechargement à chaud.

  • Rapports basés sur le motif depuis n'importe quel serveur
  • Alerte du personnel avec un bouton cliquer pour se connecter
  • Intégration facultative de Discord via webhook
  • Temps de recharge configurable et contournement des autorisations
  • Blocage de l'auto-évaluation
  • Affiche le serveur du joueur signalé
  • Autorisations séparées pour les utilisateurs, le personnel et l'administrateur
  • Rechargement de la configuration à chaud
Remarques: Métadonnées et messages en espagnol.

Installation étape par étape

Ce plugin est installé sur le proxy (BungeeCord ou Velocity), pas sur les serveurs de jeux.
  1. Téléchargez le plugin .jar et déposez-le dans le dossier plugins/ de votre serveur ou proxy.
  2. Installez l'une des dépendances dont vous avez besoin à partir de la liste des exigences.
  3. Redémarrez le serveur (ou exécutez /reload confirm) pour que le plugin démarre.
  4. Configurez le plugin via son config.yml et ses fichiers de données.
  5. Utilisez la commande reload du plugin pour appliquer les modifications sans redémarrer.

Crochets et intégrations

Le plugin se connecte automatiquement à ces plugins lorsqu'ils sont installés sur votre serveur.

Pas de hooks : il fonctionne de manière autonome, sans dépendances externes.
