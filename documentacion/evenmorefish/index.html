EvenMoreFish

Competiciones de pesca con peces personalizados.

Descargar en:GitHub

Resumen

EvenMoreFish es un plugin open-source que mejora la pesca con más de 60 peces personalizados, rarezas, tamaños y recompensas. Permite organizar competiciones programadas o lanzadas por el staff con bossbar y ranking, además de vender las capturas en la tienda /emf shop. Añade cañas y cebos personalizados, journal de capturas, estadísticas en base de datos y compatibilidad con plugins populares.

  • Más de 60 peces personalizados de serie
  • Rarezas, tamaños y recompensas configurables
  • Competiciones programadas con bossbar
  • Tienda /emf shop y venta masiva /emf sellall
  • Cañas y cebos personalizados
  • Journal de capturas y ranking /emf top
  • Base de datos SQLite/MySQL con estadísticas
  • Addons, 20+ idiomas y soporte de Folia
Notas: Plugin de terceros de Oheers, FireML y sarhatabaot; copia local de la versión 2.4.7-SNAPSHOT.

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

Economía: usa la API de Vault para cobrar y pagar (funciona con el plugin de economía que tengas).

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

WorldGuardOpcional

Regiones: integra sus zonas con las regiones protegidas de WorldGuard.

mcMMOOpcional

Habilidades: integra recompensas con las habilidades de mcMMO.

EssentialsX/CMIOpcional

Comandos básicos: compatible con los comandos y utilidades de Essentials(X).

ItemsAdder/Oraxen/NexoOpcional

Ítems: soporta ítems personalizados de ItemsAdder, Oraxen o Nexo.

HeadDatabaseOpcional

Cabezas: permite usar cabezas personalizadas de HeadDatabase en menús e ítems.

PlayerPointsOpcional

Puntos: usa PlayerPoints como moneda para recompensas y compras.

AuraSkillsOpcional

Habilidades: integra recompensas con las habilidades de AuraSkills.

DenizenOpcional

Scripts: integración con scripts de Denizen.

EcoItemsOpcional

Ítems: soporta ítems de EcoItems en recompensas y menús.

GriefPreventionOpcional

Protección: respeta las parcelas protegidas de GriefPrevention.

ItemsAdderOpcional

Ítems: soporta ítems y bloques personalizados de ItemsAdder.

NexoOpcional

Ítems: soporta ítems y modelos personalizados de Nexo.

OraxenOpcional

Ítems: soporta ítems personalizados de Oraxen.

RedProtectOpcional

Protección: respeta las regiones de RedProtect.

EssentialsOpcional

Comandos básicos: compatible con los comandos y utilidades de Essentials(X).

CMIOpcional

Compatibilidad con los comandos y utilidades de CMI.

SayanVanishOpcional

Vanish: respeta a los jugadores en modo vanish (SuperVanish, PremiumVanish, etc.).

AdvancedVanishOpcional

Vanish: respeta a los jugadores en modo vanish (SuperVanish, PremiumVanish, etc.).
