NewRankup

Rank up with requirements, prestige and rebirth.

Overview

Rankup plugin with an editable GUI and multiple per-rank requirements: money, XP levels, playtime hours, mobs, player kills and items. It adds prestige and rebirth systems with scaling costs, plus bulk rankup commands. Supports Vault, PlaceholderAPI, HeadDatabase, NPrisonCore and YAML, H2, SQLite, MySQL or MongoDB storage.

  • Rank GUI with items and Base64 icons
  • Requirements: money, XP, time, mobs, kills, items
  • Configurable prestige and rebirth systems
  • Bulk /maxrankup, /maxprestige, /maxrebirth commands
  • Rank, progress and progressbar placeholders
  • Title, sound and particle effects
  • YAML, H2, SQLite, MySQL or MongoDB storage
  • HeadDatabase and NPrisonCore support
Notes: Default messages in Spanish.

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

VaultOptional

Economy: uses the Vault API to charge and pay players (works with your economy plugin).

PlaceholderAPIOptional

Placeholders: exposes and consumes placeholders in menus, scoreboards and messages.

HeadDatabaseOptional

Heads: lets you use custom HeadDatabase heads in menus and items.

NPrisonCoreOptional

Prison: integrates progression with NPrisonCore.
