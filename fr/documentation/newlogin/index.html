NewLogin

Connectez-vous, inscrivez-vous et authentification premium pour votre réseau.

Aperçu

nSystème d'authentification de type connexion avec connexion, inscription, changement de mot de passe, déconnexion et suppression de compte. Inclut une vérification premium de style DynamicPremium lorsqu’elle est utilisée avec un proxy. Un seul pot fonctionne sur Bukkit, BungeeCord et Velocity, avec un stockage YAML, SQLite, H2 ou MySQL. Prend en charge les couleurs HEX et MiniMessage, les limites de tentative et d'IP, ainsi que Bedrock via Floodgate.

  • Connexion, inscription et changement de mot de passe
  • Vérification premium sur proxy
  • Un pot pour Bukkit, Bungee et Velocity
  • YAML, SQLite, H2 et MySQL
  • Tentatives et limites IP
  • Support du substrat rocheux via Floodgate
  • Couleurs HEX et MiniMessage
  • Protection jusqu'à la connexion
Remarques: Un seul pot pour Bukkit, Bungee et Velocity.

Installation étape par étape

  1. Téléchargez le plugin .jar et déposez-le dans le dossier plugins/ de votre serveur ou proxy.
  2. Installez l'une des dépendances dont vous avez besoin à partir de la liste des exigences.
  3. Redémarrez le serveur (ou exécutez /reload confirm) pour que le plugin démarre.
  4. Configurez le plugin via son config.yml et ses fichiers de données.
  5. Utilisez la commande reload du plugin pour appliquer les modifications sans redémarrer.

Crochets et intégrations

Le plugin se connecte automatiquement à ces plugins lorsqu'ils sont installés sur votre serveur.

FloodgateFacultatif

Bedrock : permet aux joueurs de Bedrock de rejoindre via Floodgate.

Fichiers de configuration

Chaque fichier .yml livré avec le plugin, exactement tel qu'il apparaît dans le code source. Cliquez sur l'un pour l'afficher, le copier ou le télécharger.

Les fichiers sont affichés avec leurs valeurs par défaut : copiez-les ou téléchargez-les et éditez-les dans le dossier plugins/ de votre serveur.
