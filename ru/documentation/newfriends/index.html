NewFriends

Друзья из разных сетей с личными сообщениями.

Обзор

NewFriends — это модульная система друзей для сетей BungeeCord и Velocity: игроки отправляют и принимают запросы с помощью нажимаемых кнопок, просматривают список друзей, показывающий текущий сервер каждого друга, удаляют друзей и общаются в частном порядке с помощью /f msg и /f r. Он хранит данные в H2, MySQL, MongoDB или JSON и выполняет операции асинхронно. Конфигурацию, сообщения и хранилище можно перезагружать во время выполнения.

  • Запросы на добавление в друзья с помощью кликабельных кнопок
  • Список друзей с текущим сервером и ярлыком MSG
  • Личные сообщения и быстрый ответ (/f r)
  • Хранилище H2, MySQL, MongoDB или JSON.
  • Работает на BungeeCord и Velocity.
  • Настраиваемые асинхронные операции
  • Горячая перезагрузка без перезапуска прокси
  • Дополнительная поддержка RedisBungee
Примечания: Корневая команда /friends с псевдонимами /f, /friend, /amigos и /amigo.

Пошаговая установка

Этот плагин устанавливается на прокси (BungeeCord или Velocity), а не на игровые серверы.
  1. Загрузите плагин .jar и поместите его в папку plugins/ на своем сервере или прокси.
  2. Установите любую из необходимых вам зависимостей из списка требований.
  3. Перезагрузите сервер (или запустите /reload submit), чтобы плагин загрузился.
  4. Настройте плагин через его config.yml и файлы данных.
  5. Используйте команду перезагрузки плагина, чтобы применить изменения без перезапуска.

Хуки и интеграции

Плагин автоматически подключается к этим плагинам, когда они устанавливаются на ваш сервер.

RedisBungeeНеобязательный

Мультипрокси: синхронизирует данные между прокси с помощью RedisBungee.

Конфигурационные файлы

Каждый файл .yml, поставляемый с плагином, точно такой, какой он есть в исходном коде. Нажмите один, чтобы просмотреть, скопировать или загрузить его.

Файлы отображаются со значениями по умолчанию: скопируйте или загрузите их и отредактируйте в папке plugins/ вашего сервера.

КомандаОписаниеРазрешение

  
    

      /f add <jugador>
      
    

    
  		
  Отправить запрос в друзья

  Принять запрос на добавление в друзья
