nStaffMode

Complete staff mode with moderation tools.

Overview

nStaffMode gives your staff team a complete work mode with a hotbar of tools: teleporter, player inspector, invsee, freezer, vanish, random teleport, mine detector, CPS test, ban axe and container view. It includes staff chat and owner chat over BungeeCord channels, a network-wide online staff menu, ore alerts and Discord webhooks. It also protects staff inventories and reloads the whole configuration without restarting.

Features

  • Configurable staff tool hotbar
  • Vanish, freeze, invsee and container view
  • Silent 15-second CPS test
  • Cross-server staff chat and owner chat
  • Online staff menu with teleport
  • Ban menu with configurable reasons
  • Diamond, netherite and spawner alerts
  • Discord webhooks for joins and punishments

Installation

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.
