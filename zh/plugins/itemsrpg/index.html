ItemsRPG

带有配方、效果和插件的自定义 RPG 物品。

概述

ItemsRPG 添加了自定义 RPG 物品：消耗品、无限消耗品、武器、工具、盔甲、副手物品和香草冷却物品。物品是通过游戏内 GUI 创建和编辑的，具有自定义配方、药水效果、声音、粒子和爆炸采矿等附魔。它还具有被动任务（工具急速、装甲和副手任务）、外部插件 API 和 HeadDatabase 支持。

特征

  • 定制物品：消耗品、武器、盔甲和副手
  • 游戏内物品编辑器和列表
  • 定制食谱
  • 原版和自定义冷却时间
  • 爆炸采矿附魔
  • 被动急速、护甲和副手任务
  • 外部插件 API
  • HeadDatabase 和占位符支持

权限

itemsrpg.use仅OP

允许使用 el comando 主体 /rpg（管理插件）

itemsrpg.autosmelt仅OP

允许使用拉斯赫拉米恩塔斯自动冶炼功能

itemsrpg.autosell仅OP

允许使用自动销售功能

要求

HeadDatabasePlaceholderAPIWorldGuardWorldEditpacketeventsShopGUIPlus
笔记: ItemsRPG 提供 2 个版本：带再生区域（此处记录的版本：使用选择魔杖、游戏内编辑器和 zone.yml 再生采矿区域；需要 PacketEvents）和不带再生区域（没有区域系统的相同基础）。

安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。
