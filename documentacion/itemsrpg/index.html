ItemsRPG

Items RPG personalizados con recetas, efectos y addons.

Resumen

ItemsRPG añade objetos RPG personalizados: consumibles, consumibles infinitos, armas, herramientas, armaduras, items de offhand y cooldowns vanilla. Los items se crean y editan desde menús in-game, con recetas propias, efectos de poción, sonidos, partículas y encantamientos como Explosive Mining. También incluye tareas pasivas (haste de herramientas, armadura y offhand), API de addons externos y soporte de HeadDatabase.

  • Items personalizados: consumibles, armas, armaduras y offhand
  • Editor y lista de items in-game
  • Recetas personalizadas
  • Cooldowns vanilla y propios
  • Encantamiento Explosive Mining
  • Tareas pasivas de haste, armadura y offhand
  • API de addons externos
  • Soporte de HeadDatabase y placeholders
Notas: ItemsRPG tiene 2 versiones: con regen zones (la documentada aquí: zonas de minería regenerables con varitas de selección, editor in-game y zones.yml; requiere PacketEvents) y sin regen zones (la misma base sin el sistema de zonas).

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

packeteventsRequerido

Paquetes: envía paquetes al cliente para efectos y visuales avanzados.

HeadDatabaseOpcional

Cabezas: permite usar cabezas personalizadas de HeadDatabase en menús e ítems.

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

WorldGuardOpcional

Regiones: integra sus zonas con las regiones protegidas de WorldGuard.

WorldEditOpcional

Selecciones: usa las selecciones de WorldEdit para definir áreas.

ShopGUIPlusOpcional

Integración opcional: se activa automáticamente si este plugin está instalado.
