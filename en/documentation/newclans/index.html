NewClans

Found your clan, forge alliances and rule the ranks.

Overview

A complete clan system for Paper servers. It lets players create clans with customizable tags and descriptions, manage members and roles, invite, accept war challenges and set ally or rival relations with friendly-fire control. It includes a Vault bank, teleport homes, clan chest, internal mail, logs, quests, levels and points, rankings, clan and ally chat, Discord webhook, ES/EN languages, configurable GUI menus and a developer API.

  • Create clans with tag, description and nickname
  • Roles, invites, kicks and bans
  • Ally and rival relations with FF control
  • Wars and regroup challenges between clans
  • Bank (Vault), chest, mail and clan logs
  • Teleport homes with delay and multiple homes
  • Quests, levels, points, souls and rankings
  • Clan/ally chat, spy and Discord webhook
Notes: Includes an API (NewClansAPI), PlaceholderAPI expansion and YAML/MySQL storage.

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

Economy: uses the Vault API to charge and pay players (works with your economy plugin).

PlaceholderAPIOptional

Placeholders: exposes and consumes placeholders in menus, scoreboards and messages.
