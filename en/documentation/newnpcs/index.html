newNPCS

Custom NPCs with 3D model support.

Overview

NPC system for Paper with newResources 3D model support. Create and edit NPCs in-game: entity type, name, movement, rotation, look-at-player, equipment, permission-based or manual visibility and click actions. It includes a public API with events, placeholders and respawning of all NPCs.

  • Create and edit NPCs in-game
  • 3D models via newResources
  • Right/left click actions
  • Permission-based or manual visibility
  • Equipment, look and model scale
  • Developer API with events
  • PlaceholderAPI and YAML saving
Notes: 3D integration with newResources.

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

newResourcesRequired

Resources: uses newResources custom resources.

PlaceholderAPIOptional

Placeholders: exposes and consumes placeholders in menus, scoreboards and messages.
