NewCosmetics

The ultimate cosmetics suite for your server.

Overview

A fork of ProCosmetics that adds a complete cosmetics system: gadgets, mounts, pets, morphs, arrow effects, miniatures, banners, emotes, music and more. It includes configurable GUI menus, animated treasure chests, rarities, coins and gadget ammo. Economy can use Vault, PlayerPoints or a built-in system. Supports SQLite, MySQL, MariaDB, PostgreSQL and MongoDB, with optional Redis for network sync.

  • 13 categories: gadgets, mounts, pets, morphs, emotes...
  • Animated treasure chests
  • Configurable coins, ammo and rarities
  • Customizable GUI and menu item
  • Vault, PlayerPoints or built-in economy
  • SQLite, MySQL, MariaDB, PostgreSQL and MongoDB
  • Optional Redis and placeholders
  • WorldGuard support and cosmetic restore
Notes: Fork of ProCosmetics (FilleDev).

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

NoteBlockAPIRequired

Music: plays note block music with NoteBlockAPI.

VaultOptional

Economy: uses the Vault API to charge and pay players (works with your economy plugin).

PlaceholderAPIOptional

Placeholders: exposes and consumes placeholders in menus, scoreboards and messages.

PlayerPointsOptional

Points: uses PlayerPoints as currency for rewards and purchases.

WorldGuardOptional

Regions: integrates its zones with WorldGuard protected regions.

WorldEditOptional

Selections: uses WorldEdit selections to define areas.

CMIOptional

Compatibility with CMI commands and utilities.

EssentialsOptional

Basic commands: compatible with Essentials(X) commands and utilities.

MVdWPlaceholderAPIOptional

Placeholders: extra placeholder support via MVdWPlaceholderAPI.

Multiverse-CoreOptional

Worlds: compatible with Multiverse-Core managed worlds.

PremiumVanishOptional

Vanish: respects players in vanish mode (SuperVanish, PremiumVanish, etc.).

PlotSquaredOptional

Plots: integrates its features with PlotSquared plots.

SuperVanishOptional

Vanish: respects players in vanish mode (SuperVanish, PremiumVanish, etc.).
