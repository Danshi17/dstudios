EvenMoreFish

완전히 맞춤화된 물고기를 이용한 낚시 대회.

다운로드 대상:GitHub

개요

EvenMoreFish는 60개 이상의 맞춤형 물고기, 희귀도, 길이 및 보상으로 낚시를 업그레이드하는 오픈 소스 플러그인입니다. 보스바와 리더보드를 사용하여 예정된 대회나 직원이 주최하는 대회를 운영할 수 있으며 /emf 상점에서 상품을 판매할 수도 있습니다. 맞춤형 낚싯대와 미끼, 물고기 일지, 데이터베이스 기반 통계 및 인기 플러그인과의 호환성을 추가합니다.

  • 즉시 사용 가능한 60가지 이상의 맞춤형 물고기
  • 구성 가능한 희귀도, 길이 및 보상
  • 보스바를 이용한 예정된 대회
  • /emf shop 및 /emf Sellall을 통한 대량 판매
  • 맞춤형 낚싯대 및 미끼
  • 물고기 일지 및 /emf 상위 리더보드
  • catch 통계가 포함된 SQLite/MySQL 데이터베이스
  • 애드온, 20개 이상의 로케일 및 Folia 지원
메모: Oheers, FireML 및 sarhatabaot의 타사 플러그인; 버전 2.4.7-SNAPSHOT의 로컬 복사본.

단계별 설치

  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.

후크 및 통합

플러그인은 서버에 설치될 때 이러한 플러그인과 자동으로 연결됩니다.

Vault선택 과목

경제: Vault API를 사용하여 플레이어에게 요금을 청구하고 지불합니다(경제 플러그인과 함께 작동).

PlaceholderAPI선택 과목

자리 표시자: 메뉴, 점수판, 메시지에 자리 표시자를 노출하고 사용합니다.

WorldGuard선택 과목

지역: 해당 영역을 WorldGuard 보호 지역과 통합합니다.

mcMMO선택 과목

스킬: mcMMO 스킬과 보상을 통합합니다.

EssentialsX/CMI선택 과목

기본 명령: Essentials(X) 명령 및 유틸리티와 호환됩니다.

ItemsAdder/Oraxen/Nexo선택 과목

아이템: ItemsAdder, Oraxen 또는 Nexo의 사용자 정의 아이템을 지원합니다.

HeadDatabase선택 과목

헤드: 메뉴와 항목에서 사용자 정의 HeadDatabase 헤드를 사용할 수 있습니다.

PlayerPoints선택 과목

포인트: PlayerPoint를 보상 및 구매를 위한 통화로 사용합니다.

AuraSkills선택 과목

스킬: AuraSkills 스킬과 보상을 통합합니다.

Denizen선택 과목

스크립트: Denizen 스크립트와의 통합.

EcoItems선택 과목

아이템: 보상과 메뉴에서 EcoItems 아이템을 지원합니다.

GriefPrevention선택 과목

보호: GriefPrevention으로 보호되는 주장을 존중합니다.

ItemsAdder선택 과목

항목: ItemsAdder 사용자 정의 항목 및 블록을 지원합니다.

Nexo선택 과목

아이템: Nexo 커스텀 아이템과 모델을 지원합니다.

Oraxen선택 과목

아이템: Oraxen 커스텀 아이템을 지원합니다.

RedProtect선택 과목

보호: RedProtect 지역을 존중합니다.

Essentials선택 과목

기본 명령: Essentials(X) 명령 및 유틸리티와 호환됩니다.

CMI선택 과목

CMI 명령 및 유틸리티와의 호환성.

SayanVanish선택 과목

소멸: 소멸 모드(SuperVanish, PremiumVanish 등)의 플레이어를 존중합니다.

AdvancedVanish선택 과목

소멸: 소멸 모드(SuperVanish, PremiumVanish 등)의 플레이어를 존중합니다.

파일은 기본값으로 표시됩니다. 파일을 복사하거나 다운로드하여 서버의 plugins/ 폴더에서 편집하세요.

명령

        
명령설명허가

  
    

      /emf shop
      
    

    
  		
  상점을 열어 생선을 판매하세요
  emf.shop




  
    

      /emf sellall
      
    

    
  		
  인벤토리에 있는 모든 생선을 판매하세요
  emf.sellall




  
    

      /emf top
      
    

    
  		
  플레이어 리더보드 표시
  emf.top




  
    

      /emf journal
      
    

    
  		
  물고기 일기를 열어보세요
  emf.journal




  
    

      /emf toggle
      
    

    
  		
  낚시, 보스바 전환, 메시지 잡기
  emf.toggle




  
    

      /emf next
      
    

    
  		
  다음 대회가 언제인지 표시
  emf.next




  
    

      /emf applybaits
      
    

    
  		
  쥐고 있는 낚싯대에 미끼를 바릅니다.
  emf.applybaits




  
    

      /emf admin competition start
      
    

    
  		
  수동으로 대회 시작
  emf.admin


      


      

        
권한

        

  
emf.*OP만 해당16 어린이 권한

  






  
emf.adminOP만 해당2 어린이 권한

  






  
emf.admin.update.notifyOP만 해당

  
사용자에게 업데이트에 대한 알림을 보낼 수 있습니다.





  
emf.admin.migrateOP만 해당

  
사용자가 마이그레이션 명령을 사용할 수 있습니다.







  
emf.userOP만 해당12 어린이 권한

  






  
emf.toggleOP만 해당3 어린이 권한

  
사용자가 EMF를 전환할 수 있습니다.







  
emf.toggle.fishingOP만 해당

  




  
emf.toggle.bossbarOP만 해당

  




  
emf.toggle.catchmessageOP만 해당

  






  
emf.topOP만 해당

  
사용자가 /emf top을 사용할 수 있도록 허용합니다.





  
emf.shopOP만 해당

  
사용자가 /emf shop을 사용할 수 있도록 허용합니다.





  
emf.use_rodOP만 해당

  
사용자가 EMF 막대를 사용할 수 있습니다.





  
emf.sellallOP만 해당

  
사용자가 Sellall을 사용할 수 있도록 허용합니다.





  
emf.help모든 사람

  
사용자가 도움말 메시지를 볼 수 있습니다.





  
emf.nextOP만 해당

  
사용자가 다음 대회가 언제인지 확인할 수 있습니다.





  
emf.applybaitsOP만 해당

  
사용자가 낚싯대에 미끼를 적용할 수 있습니다.





  
emf.journalOP만 해당

  
물고기 일지에 접근할 수 있습니다.
