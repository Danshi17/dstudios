AfkZone

자동 보상과 게임 내 편집기가 포함된 AFK 영역.

개요

AfkZone은 구성 가능한 간격과 가중치가 부여된 명령 보상을 통해 플레이어가 AFK 동안 보상을 받을 수 있는 영역을 만듭니다. 여기에는 메뉴, 선택 도끼, 입자 미리보기가 포함된 완전한 게임 내 편집기와 WorldGuard 지역 지원이 포함되어 있습니다. 또한 IP당 보상 한도, 이동 시 재설정, 입장/탈퇴/진행 알림 및 자리 표시자를 제공합니다.

특징

  • 메뉴와 선택 도끼가 있는 게임 내 편집기
  • 입자 미리보기가 포함된 선택 기반 영역
  • 간격당 가중치 명령 보상
  • WorldGuard 지역 지원
  • IP당 보상 한도
  • 입장, 퇴장 및 진행 알림
  • 다시 시작하지 않고 핫 리로드

명령

명령설명허가
/afkzone
별칭: /az · /afkz
 AfkZone의 코만도 교장 afkzone.admin
/afkzone menu
게임 내 편집기를 엽니다. afkzone.admin
/afkzone edit [zona]
영역을 나열하거나 편집합니다. afkzone.admin
/afkzone tool
선택도끼를 준다 afkzone.admin
/afkzone create <nombre>
선택 영역을 생성합니다. afkzone.admin
/afkzone cancel
현재 선택을 취소합니다. afkzone.admin
/afkzone reload
구성 및 영역을 다시 로드합니다. afkzone.admin

권한

afkzone.adminOP만 해당

AfkZone 관리자와 게임 내 편집자를 사용할 수 있도록 허용합니다.

요구사항

WorldGuardPlaceholderAPI
메모: 보상은 zones.yml의 명령으로 정의됩니다.

설치

  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.
