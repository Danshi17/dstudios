NewJobs

13 profesiones con XP, misiones y contratos.

Resumen

Sistema de trabajos con 13 profesiones predeterminadas (minero, leñador, granjero, pescador, cazador, constructor, excavador, artesano, encantador, alquimista, herrero, ganadero y explorador). Cada acción otorga dinero, XP y puntos, con múltiples trabajos simultáneos, misiones diarias, contratos temporales, recompensas por nivel y prestigio. Incluye menús GUI totalmente configurables y una BossBar de progreso. La economía puede entregarse vía Vault o por comandos.

  • 13 trabajos por defecto, ampliables en YAML
  • Dinero, XP y puntos por cada acción
  • Misiones diarias y contratos temporales
  • Recompensas por nivel y prestigio
  • Menús configurables con acciones y sonidos
  • BossBar de XP por trabajo
  • Economía Vault o por comandos
  • Protección anti-farming de bloques
Notas: Paper 1.18.2+ y Java 17+.

Instalación paso a paso

  1. Descarga el .jar del plugin y colócalo en la carpeta plugins/ de tu servidor o proxy.
  2. Instala las dependencias que uses de la lista de requisitos.
  3. Reinicia el servidor (o ejecuta /reload confirm) para que el plugin arranque.
  4. Configura el plugin desde su config.yml y sus archivos de datos.
  5. Usa el comando de recarga del plugin para aplicar cambios sin reiniciar.

Hooks e integraciones

El plugin se conecta solo con estos plugins cuando están instalados en tu servidor.

VaultOpcional

Economía: usa la API de Vault para cobrar y pagar (funciona con el plugin de economía que tengas).

PlaceholderAPIOpcional

Placeholders: expone y consume placeholders en menús, scoreboards y mensajes.

WorldGuardOpcional

Regiones: integra sus zonas con las regiones protegidas de WorldGuard.

Archivos de configuración

Todos los archivos .yml que trae el plugin, tal cual vienen en el código fuente. Pulsa uno para verlo, copiarlo o descargarlo.

Los archivos se muestran con sus valores por defecto: cópialos o descárgalos y edítalos en la carpeta plugins/ de tu servidor.
