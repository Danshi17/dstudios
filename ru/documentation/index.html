Как установить любой плагин

  1. Загрузите плагин .jar и поместите его в папку plugins/ на своем сервере или прокси.
  2. Установите любую из необходимых вам зависимостей из списка требований.
  3. Перезагрузите сервер (или запустите /reload submit), чтобы плагин загрузился.
  4. Настройте плагин через его config.yml и файлы данных.
  5. Используйте команду перезагрузки плагина, чтобы применить изменения без перезапуска.
