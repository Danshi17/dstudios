nStaffMode

带有审核工具的完整员工模式。

概述

nStaffMode 为您的员工团队提供了一个完整的工作模式，其中包含工具快捷栏：传送器、玩家检查器、invsee、冷冻器、消失、随机传送、地雷探测器、CPS 测试、禁令斧头和容器视图。它包括通过 BungeeCord 频道进行员工聊天和业主聊天、全网络在线员工菜单、矿石警报和 Discord webhooks。它还可以保护员工库存并重新加载整个配置而无需重新启动。

  • 可配置的员工工具热栏
  • 消失、冻结、invsee 和容器视图
  • 静默 15 秒 CPS 测试
  • 跨服务器员工聊天和老板聊天
  • 带传送功能的在线员工菜单
  • 禁止菜单可配置原因
  • 钻石、下界合金和生成器警报
  • 用于加入和惩罚的 Discord webhooks
笔记: 西班牙语配置和消息；版本 0.1-RC。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

BungeeCord选修的

网络：通过 BungeeCord 进行消息传递和网络功能。

nstaffmode.staffonline仅OP

  
允许使用 /staffonline para ver el 菜单 de Staff。

允许远程传送员工到/staffonline。





  
nstaffmode.command仅OP

  
允许 usar el comando /staffmode。





  
nstaffmode.reload仅OP

  
允许重新配置插件。





  
nstaffmode.use.teleporter仅OP

  
允许使用远程传输器。





  
nstaffmode.use.inspector仅OP

  
允许使用司法检查员。





  
nstaffmode.use.invsee仅OP

  
允许使用发明检查员。





  
nstaffmode.use.freezer仅OP

  
允许使用凝结剂。





  
nstaffmode.use.kicker仅OP

  
允许使用踢球。





  
nstaffmode.use.banner仅OP

  
允许使用 el hach​​a de ban。





  
nstaffmode.bypass.freeze仅OP

  
Evita que el jugador pueda ser congelado。





  
nstaffmode.silent.joinleave仅OP

  
允许服务员沉默。





  
nstaffmode.use.vanish仅OP

  
允许使用 el item para activar/desactivar el modo 消失。





  
nstaffmode.vanish.see仅OP

nstaffmode.use.randomtp仅OP
