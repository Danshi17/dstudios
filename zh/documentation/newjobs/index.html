NewJobs

13 个具有 XP、任务和合同的职业。

概述

具有 13 个默认职业的职业系统（矿工、樵夫、农民、渔夫、猎人、建筑商、挖掘者、工匠、附魔师、酿酒师、武器匠、牧场主和探险家）。行动可授予金钱、经验值和积分，同时提供多项工作、每日任务、临时合同、等级奖励和声望。包括完全可配置的 GUI 菜单和进度 BossBar。经济是通过 Vault 或命令来交付的。

  • 13 个默认作业，可通过 YAML 扩展
  • 每次行动的金钱、XP 和积分
  • 每日任务和临时合同
  • 等级奖励和声望
  • 带有动作和声音的可配置菜单
  • 按职位 XP BossBar
  • 保险库或基于命令的经济
  • 防耕块保护
笔记: 论文 1.18.2+ 和 Java 17+。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

Vault选修的

经济：使用 Vault API 向玩家收费和付款（与您的经济插件配合使用）。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

WorldGuard选修的

区域：将其区域与 WorldGuard 保护区整合。
