NewChatColor

使用十六进制、渐变等自定义您的聊天颜色。

概述

具有自定义颜色创建功能的聊天颜色插件。玩家打开带有基于权限的预设颜色的 GUI 菜单，并可以使用旧代码、十六进制或 MiniMessage（渐变和彩虹）创建自己的颜色，并支付可配置的 Vault 成本。它包括每个等级的限制、公共或私人颜色、奖金插槽和用于分配、删除或管理颜色的管理命令。

特征

  • 具有预设颜色的 GUI 菜单
  • 自定义颜色：传统颜色、十六进制颜色和 MiniMessage
  • 带预览的渐变和彩虹
  • 通过 Vault 进行的每等级限制和成本
  • 公共和私人颜色
  • 为玩家提供的奖励颜色槽
  • 管理命令：setcolor、unset、give、delete

命令

命令描述允许
/colors
别名: /color · /chatcolor · /cc
 Abre el menu de colores de chat / gestiona tu color。 —
/coloradmin
别名: /ccadmin
 NewChatColor 的管理员。 newchatcolor.admin
/colors gui
打开主菜单 newchatcolor.use
/colors create <public|private> <nombre> <patron>
创建自定义颜色 newchatcolor.create
/coloradmin give <jugador> <cantidad>
提供额外的颜色槽 newchatcolor.admin

权限

newchatcolor.use每个人

允许使用/颜色

newchatcolor.create每个人

允许个性化颜色

newchatcolor.create.free仅OP

个性化色彩创造

newchatcolor.create.bypasslimit仅OP

忽略个性化创作色彩的限制

newchatcolor.admin仅OP

访问 /coloradmin

newchatcolor.public.edit.others仅OP

Editar/eliminar/despublicar colores publicos de otros jugadores

createcolor.default每个人

有限的个性化基础颜色（范围默认）

createcolor.vip没有人

限量 VIP 个性化色彩

createcolor.mvp没有人

个性化色彩限量 MVP

createcolor.premium没有人

个性化颜色限制高级 (usualmente ilimitado)

安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。
