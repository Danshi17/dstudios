NewCosmetics

适合您服务器的终极化妆品套件。

概述

ProCosmetics 的一个分支，添加了完整的化妆品系统：小工具、坐骑、宠物、变形、箭头效果、微缩模型、横幅、表情、音乐等等。它包括可配置的 GUI 菜单、动画宝箱、稀有物品、硬币和小工具弹药。经济可以使用 Vault、PlayerPoints 或内置系统。支持 SQLite、MySQL、MariaDB、PostgreSQL 和 MongoDB，可选配 Redis 进行网络同步。

  • 13 个类别：小工具、坐骑、宠物、变形、表情...
  • 动画宝箱
  • 可配置的硬币、弹药和稀有物品
  • 可定制的 GUI 和菜单项
  • Vault、PlayerPoints 或内置经济
  • SQLite、MySQL、MariaDB、PostgreSQL 和 MongoDB
  • 可选的 Redis 和占位符
  • WorldGuard 支持和外观恢复
笔记: ProCosmetics (FilleDev) 的分叉。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

NoteBlockAPI必需的

音乐：使用 NoteBlockAPI 播放音符块音乐。

Vault选修的

经济：使用 Vault API 向玩家收费和付款（与您的经济插件配合使用）。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

PlayerPoints选修的

积分：使用 PlayerPoints 作为奖励和购买的货币。

WorldGuard选修的

区域：将其区域与 WorldGuard 保护区整合。

WorldEdit选修的

选择：使用 WorldEdit 选择来定义区域。

CMI选修的

与 CMI 命令和实用程序兼容。

Essentials选修的

基本命令：与 Essentials(X) 命令和实用程序兼容。

MVdWPlaceholderAPI选修的

占位符：通过 MVdWPlaceholderAPI 提供额外的占位符支持。

Multiverse-Core选修的

世界：与 Multiverse-Core 管理的世界兼容。

PremiumVanish选修的

Vanish：尊重处于消失模式的玩家（SuperVanish、PremiumVanish 等）。

PlotSquared选修的

绘图：将其功能与 PlotSquared 绘图集成。

SuperVanish选修的

Vanish：尊重处于消失模式的玩家（SuperVanish、PremiumVanish 等）。
