HubCore

终极大堂核心：菜单、快捷栏等。

概述

HubCore 是一个完整的大厅核心：/hubspawn、主世界保护、可配置的热键栏、带有操作的菜单系统和 BungeeCord 服务器导航器。它添加了记分板、选项卡列表、标签和聊天颜色、化妆品、启动板、EnderButt、PvP 模式和基于排名的加入/退出消息。模块可以在游戏中和从 config.yml 中切换。

  • 通过 /hub 和世界保护生成
  • 可配置的热栏、菜单和导航器
  • 记分板和表格
  • 标签和聊天颜色
  • 发射板和 EnderButt
  • PvP 模式和 /mod 审核命令
  • 游戏中可切换的模块
  • 基于排名的加入和退出消息
笔记: 许多模块可以从 /lobbyadmin 实时切换。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

LuckPerms选修的

权限：从LuckPerms读取等级和权限。

HeadDatabase选修的

Heads：允许您在菜单和项目中使用自定义 HeadDatabase 头。

Vault选修的

经济：使用 Vault API 向玩家收费和付款（与您的经济插件配合使用）。
