NewDTC

摧毁核心：有奖励的 PvP 活动。

概述

摧毁核心 PvP 活动：管理员用魔杖创建核心，玩家竞争摧毁它们。它使用 PacketEvents 有效地渲染块和全息图。包括可配置的记分板、获胜者排行榜、伤害统计数据和游戏内配置编辑器。

  • 使用魔杖创建和管理核心
  • 基于数据包的块和全息图
  • 每个玩家可配置的记分板
  • 核心赢得排行榜和统计数据
  • 游戏内配置编辑器
  • WorldGuard 标志 newdtc-core
  • 占位符和 TAB 挂钩
笔记: PacketEvents 是必需的。

逐步安装

  1. 下载插件 .jar 并将其放入服务器或代理 plugins/ 文件夹中。
  2. 从需求列表中安装您需要的任何依赖项。
  3. 重新启动服务器（或运行 /reload recognize）以便插件启动。
  4. 通过其 config.yml 和数据文件配置插件。
  5. 使用插件的重新加载命令应用更改而无需重新启动。

挂钩和集成

当这些插件安装在您的服务器上时，该插件会自动与它们连接。

packetevents必需的

数据包：发送客户端数据包以获得高级效果和视觉效果。

WorldGuard选修的

区域：将其区域与 WorldGuard 保护区整合。

PlaceholderAPI选修的

占位符：公开并使用菜单、记分板和消息中的占位符。

TAB选修的

Tablist：通过TAB自定义选项卡列表。
