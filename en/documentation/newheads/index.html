NewHeads

Floating heads with text and interaction to decorate your server.

Overview

NewHeads lets you place floating heads that rotate, display multi-colored text and react to clicks. It renders with PacketEvents (no entities) for excellent performance, with adjustable view distance, click cooldown and hitbox. It supports HeadDatabase for custom heads, FancyHolograms for holograms and can grant ExcellentCrates rewards on interaction.

  • Floating heads rendered with packets (no entities)
  • Multi-colored text with configurable offset and spacing
  • Adjustable rotation, view distance and hitbox
  • Click actions: commands, messages or menus
  • Custom heads with HeadDatabase
  • Holograms with FancyHolograms and crates with ExcellentCrates

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

packeteventsRequired

Packets: sends client packets for advanced effects and visuals.

HeadDatabaseOptional

Heads: lets you use custom HeadDatabase heads in menus and items.

FancyHologramsOptional

Holograms: displays holograms with FancyHolograms.

ExcellentCratesOptional

Crates: integrates rewards and keys with ExcellentCrates.
