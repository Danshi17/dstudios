NewFriends

Amis inter-réseaux avec messagerie privée.

Aperçu

NewFriends est un système d'amis modulaire pour les réseaux BungeeCord et Velocity : les joueurs envoient et acceptent des demandes avec des boutons cliquables, parcourent une liste d'amis affichant le serveur actuel de chaque ami, suppriment des amis et discutent en privé avec /f msg et /f r. Il stocke les données au format H2, MySQL, MongoDB ou JSON et exécute les opérations de manière asynchrone. La configuration, les messages et le stockage peuvent être rechargés au moment de l'exécution.

  • Demandes d'amis avec boutons cliquables
  • Liste d'amis avec le serveur actuel et le raccourci MSG
  • Messages privés et réponse rapide (/f r)
  • Stockage H2, MySQL, MongoDB ou JSON
  • Fonctionne sur BungeeCord et Velocity
  • Opérations asynchrones configurables
  • Rechargement à chaud sans redémarrer le proxy
  • Prise en charge facultative de RedisBungee
Remarques: Commande racine /friends avec les alias /f, /friend, /amigos et /amigo.

Installation étape par étape

Ce plugin est installé sur le proxy (BungeeCord ou Velocity), pas sur les serveurs de jeux.
  1. Téléchargez le plugin .jar et déposez-le dans le dossier plugins/ de votre serveur ou proxy.
  2. Installez l'une des dépendances dont vous avez besoin à partir de la liste des exigences.
  3. Redémarrez le serveur (ou exécutez /reload confirm) pour que le plugin démarre.
  4. Configurez le plugin via son config.yml et ses fichiers de données.
  5. Utilisez la commande reload du plugin pour appliquer les modifications sans redémarrer.

Crochets et intégrations

Le plugin se connecte automatiquement à ces plugins lorsqu'ils sont installés sur votre serveur.

RedisBungeeFacultatif

Multi-proxy : synchronise les données entre les proxys avec RedisBungee.

Fichiers de configuration

Chaque fichier .yml livré avec le plugin, exactement tel qu'il apparaît dans le code source. Cliquez sur l'un pour l'afficher, le copier ou le télécharger.

Les fichiers sont affichés avec leurs valeurs par défaut : copiez-les ou téléchargez-les et éditez-les dans le dossier plugins/ de votre serveur.
