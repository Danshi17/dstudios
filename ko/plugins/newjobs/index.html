NewJobs

XP, 퀘스트, 계약이 포함된 13가지 직업.

개요

13가지 기본 직업(광부, 나무꾼, 농부, 어부, 사냥꾼, 건축업자, 채굴자, 공예가, 마법부여사, 양조업자, 무기제작자, 목장주, 탐험가)이 있는 작업 시스템. 액션은 여러 동시 작업, 일일 퀘스트, 임시 계약, 레벨 보상 및 명성을 통해 돈, XP 및 포인트를 부여합니다. 완전히 구성 가능한 GUI 메뉴와 진행 BossBar가 포함되어 있습니다. 경제는 Vault 또는 명령을 통해 제공됩니다.

특징

  • 13개의 기본 작업, YAML을 통해 확장 가능
  • 행동당 돈, XP 및 포인트
  • 일일 퀘스트 및 임시 계약
  • 레벨 보상과 명성
  • 동작과 소리로 구성 가능한 메뉴
  • 직업별 XP BossBar
  • Vault 또는 명령 기반 경제
  • 반농업 차단 보호

명령

명령설명허가
/jobs
별칭: /job · /trabajos · /trabajo · /newjobs
 NewJobs의 작업 패널에 대해 알아보기 —
/jobs sources
직업별 활동지급 newjobs.use
/jobs prestige
최대 레벨의 프레스티지 newjobs.use
/jobs admin
XP, 포인트 또는 레벨 추가 newjobs.admin

권한

newjobs.use모든 사람
newjobs.adminOP만 해당
newjobs.bypass.limitOP만 해당
newjobs.bypass.worldOP만 해당

요구사항

VaultPlaceholderAPIWorldGuard
메모: Paper 1.18.2+ 및 Java 17+.

설치

  1. 플러그인 .jar을 다운로드하여 서버 또는 프록시 plugins/ 폴더에 놓습니다.
  2. 요구 사항 목록에서 필요한 종속성을 설치합니다.
  3. 플러그인이 부팅되도록 서버를 다시 시작하거나 /reload verify를 실행하세요.
  4. config.yml 및 데이터 파일을 통해 플러그인을 구성합니다.
  5. 다시 시작하지 않고 변경 사항을 적용하려면 플러그인의 reload 명령을 사용하세요.
