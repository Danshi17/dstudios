ItemsRPG

Custom RPG items with recipes, effects and addons.

Overview

ItemsRPG adds custom RPG items: consumables, infinite consumables, weapons, tools, armor, offhand items and vanilla-cooldown items. Items are created and edited through in-game GUIs, with custom recipes, potion effects, sounds, particles and enchants like Explosive Mining. It also features passive tasks (tool haste, armor and offhand), an external addon API and HeadDatabase support.

  • Custom items: consumables, weapons, armor and offhand
  • In-game item editor and list
  • Custom recipes
  • Vanilla and custom cooldowns
  • Explosive Mining enchant
  • Passive haste, armor and offhand tasks
  • External addon API
  • HeadDatabase and placeholder support
Notes: ItemsRPG ships in 2 versions: with regen zones (the one documented here: regenerating mining zones with selection wands, an in-game editor and zones.yml; requires PacketEvents) and without regen zones (the same base without the zone system).

Step-by-step install

  1. Download the plugin .jar and drop it into your server or proxy plugins/ folder.
  2. Install any of the dependencies you need from the requirements list.
  3. Restart the server (or run /reload confirm) so the plugin boots up.
  4. Configure the plugin through its config.yml and data files.
  5. Use the plugin's reload command to apply changes without restarting.

Hooks & integrations

The plugin connects automatically with these plugins when they are installed on your server.

packeteventsRequired

Packets: sends client packets for advanced effects and visuals.

HeadDatabaseOptional

Heads: lets you use custom HeadDatabase heads in menus and items.

PlaceholderAPIOptional

Placeholders: exposes and consumes placeholders in menus, scoreboards and messages.

WorldGuardOptional

Regions: integrates its zones with WorldGuard protected regions.

WorldEditOptional

Selections: uses WorldEdit selections to define areas.

ShopGUIPlusOptional

Optional integration: enabled automatically when this plugin is installed.
